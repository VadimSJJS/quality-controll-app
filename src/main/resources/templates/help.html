1. Основная информация

Добро пожаловать в систему учёта несоответствующей продукции БМЗ. Эта система предназначена для отслеживания и документирования всех выявленных дефектов на производстве.

Основные возможности:

  • Регистрация несоответствий продукции
  • Фильтрация и поиск записей
  • Генерация отчетов и аналитики
  • Экспорт данных в Excel
2. Виды несоответствий

В системе используются виды несоответствий из справочника. Вы можете:

  • Просматривать список видов дефектов
  • Добавлять новые виды дефектов (только для администраторов и OTK)
  • Редактировать существующие виды
  • Удалять виды, которые не используются в записях

Важно: удалить вид дефекта можно только если он ещё не был использован вниках записях, иначе это испортит отчеты.

3. Журнал несоответствий

Журнал содержит все зарегистрированные записи несоответствий. Здесь вы можете:

  • Просматривать список записей с постраничной навигацией
  • Применять фильтры для narrowing down результатов
  • Сортировать записи по различным критериям (по дате, по очереди добавления)
  • Экспортировать данные в Excel
  • Импортировать данные из шаблона Excel

Структура журнала включает 24 колонки данных, соответствующие Приложению А в документации.

Доступные фильтры: по дате, по участку, по виду несоответствия, по номеру катушки, по диаметру, по массе, по статусу.

4. Добавление записи

Для добавления новой записи несоответствия заполните форму следующими обязательными полями:

  • Дата выявления — когда дефект был обнаружен
  • Участок — производственное место (код автоматически подставляется при выборе)
  • Источник выявления — где произошла регистрация
  • Вес — масса продукции в тоннах (должна быть положительным числом)
  • Вид несоответствия — из справочника (можно добавить новое название)
  • Оператор — табельный номер (4–6 цифр)

Дополнительные поля по участкам:

  • На канатке: возможно указание подпричины и примечаний (убедитесь, что выбрана причина перед вводом подпричины)
  • На гальванике: ввод диаметра — marque сталей подтягивается автоматически при вводе номера плавки (whs_100)
  • Восстановление массы: сумма восстановлено + переназначено + брак = общая масса (валидация суммы)

После сохранения запись перезагружается через 2.5 секунды для отображения обновленных данных.

5. Фильтры и поиск

В журнале доступны следующие фильтры:

  • По дате выявления
  • По участке/ставению
  • По виду несоответствия
  • По номеру катушки
  • По диаметру
  • По массе/весу
  • По статусу

Фильтры сохраняются в локальном хранилище браузера (localStorage), и при переключении вкладок данные сохраняются.

Для сброса всех фильтров нажмите кнопку "Сбросить" в панели фильтров.

Для сложного поиска используйте комбинацию нескольких фильтров одновременно.

Колонка "Номер стана" это и есть "Оборудование" — используйте поле оборудования для фильтрации.

6. Диагностика и решение проблем

Частые вопросы и решения:

Проверьте валидацию: диаметр должен быть числом с допустимым диапазоном. Кнопка сохранения может "зависать" при некорректных значениях полей. Убедитесь, что все обязательные поля заполнены корректно.

Убедитесь, что введен корректный номер катушки. Фильтр ищет точные совпадения в поле reelNumber. Используйте частичный поиск, вводя начало номера катушки. Совет: номер катушки должен соответствовать оборудованию (стàn), проверьте поле «Оборудование» в карточке записи.

Фильтры сохраняются в localStorage браузера. Если они сбрасываются, попробуйте очистить кэш браузера или убедись, что используете один и тот же браузер.

Убедитесь, что перед вводом подпричины выбрана причина дефекта. Поле подпричины становится доступным только после выбора причины.

При добавлении серии записей на одном участке система запоминает последний выбранный участок. Если записи не сохраняются, проверьте транзакционность формы и наличие обязательных полей.

При вводе номера плавки (heat number) система автоматически подтягивает марку стали из справочника (функция whs_100). Если марка не подтягивается: проверьте, что номер плавки существует в справочнике сталей, или попробуйте ввести число без ведущих нулей. Если марка все равно не подтягивается, возможно, нужна перезагрузка страницы или очистка кэша браузера.

В записи о несоответствии фиксируется оператор (табельный номер), который进行了 the recording. Дополнительные поля "номер перемотки" и "линия инспекции" доступны в настройках участка. Для доступа к полям перемотки и линии инспекции: зайдите в настройки участка (админка) и убедитесь, что включены соответствующие опции. Номер перемотки — это номер станка/рельса, а линия инспекции — линия производственного контроля.
