# Quality Control App

Система учёта и анализа несоответствующей продукции.

## Стек

- **Spring Boot 3.4** — Java 17, Maven 3.9
- **Oracle 11g** (ojdbc11), Hibernate 6
- **Thymeleaf** + Bootstrap 5, Chart.js, DataTables
- **Spring Security** — вход по табельному номеру + пароль из `V_PERSONAL_STPC2`

## Запуск

```bash
mvn spring-boot:run
```

Приложение стартует на HTTPS:8443. Для локальной разработки в `.env.local` можно указать:

```
SERVER_PORT=8082
SERVER_SSL_ENABLED=false
APP_SECURITY_FULL_ACCESS=true
```

## Что умеет

**Журнал несоответствий**

- Таблица: дата, диаметр, оборудование (номер стана), вид несоответствия, № катушки, масса (т), статус, действия
- Фильтры: период, участок, вид/причина/подпричина дефекта, диаметр, марка стали, оборудование, бригада, источник обнаружения
- Карточка записи с историей доработок
- Добавление / редактирование / удаление записей
- Импорт из Excel (шаблон + загрузка файла)

**Отчёты (экспорт в Excel / Word)**

- По участку
- По виду продукции (диаметр / ширина / толщина)
- По видам продукции и причинам
- По бригаде
- По оборудованию
- По персоналу
- По цеху
- По вине
- Свод по актам
- Дефекты по оборудованию
- Дефекты по персоналу
- Диаграмма Парето
- Распределение по бригадам / оборудованию

**Справочники**

Виды дефектов, причины, подпричины, типы доработки, участки, диаметры, марки стали, источники обнаружения, роли персонала.

## Структура

```
src/main/java/com/vadimsjjs/qualitycontrollapp/
├── controller/          # REST + веб-контроллеры
├── dto/                 # DTO для API и отчётов
├── entity/              # JPA-сущности
├── repository/          # Spring Data JPA
├── service/             # Бизнес-логика
├── security/            # Аутентификация, роли
├── config/              # Настройки Spring
└── QualityControllAppApplication.java
```

## Роли

| Роль        | Просмотр | Редактирование | Удаление |
|-------------|----------|----------------|----------|
| ОТК / ППБ   | ✅       | ✅             |          |
| ОТК_СТАРШИЙ | ✅       | ✅             | ✅       |
| ADMIN       | ✅       | ✅             | ✅       |

Режим `app.security.full-access=true` (по умолчанию) даёт полный доступ всем авторизованным.

## База данных

Миграции применяются вручную через SQL*Plus (Flyway исключён из-за потери поддержки Oracle 11g в Community Edition).

## Конфигурация

- `.env` — общие настройки (БД, SSL)
- `.env.local` — локальные перекрытия (не попадает в git)
- `.env.example` — шаблон для копирования
