# Quality Control App

**Система учёта и анализа несоответствующей продукции** для сталепроволочного цеха №2 (СтПЦ-2) ОАО «БМЗ — УКХ «БМК».

Программа призвана заменить устаревшую систему на базе PARADOX (1992 г.) и обеспечить:
- **Регистрацию** несоответствующей исправимой продукции и брака по всем технологическим участкам.
- **Учёт доработки** (восстановления/переназначения) продукции.
- **Формирование отчётов** по качеству за сутки, неделю, месяц, квартал, полугодие, год.
- **Построение диаграмм Парето** и гистограмм для анализа причин дефектов.
